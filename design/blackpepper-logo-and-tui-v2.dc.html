The status vocabulary has already spent four of the six usable hues.

That is the case against the ember. At truecolor it reads as its own thing, but there is no orange in the 16-colour set — it degrades to yellow, which is exactly the colour of an agent waiting on you. On ConnectBot the brand mark and the one alert that matters become indistinguishable. It is also, bluntly, the house colour of every LLM tool shipped in the last two years.
The original code already knew this: today's MANAGE badge is Magenta on Black. Magenta is the only hue the status vocabulary does not need.
How to read the specimens
Each option below shows the four places the accent is ever allowed — the bp anchor, the mode badge, the selected row, the : prompt — sitting directly beside a ! asks row. If your eye has to work out which of the two is the alert, the accent has failed, regardless of how it looks alone.
The 16-col strip on each shows what the terminal actually paints when there is no truecolor to degrade from.

Worth checking, because a hybrid palette cannot pin a lightness. The accent is emitted as one hue with two lightnesses — the client already knows the terminal's background from OSC 11, so it picks the dark-background or light-background variant the same way it picks a colour tier. Everything else on the row is a named ANSI colour and follows the user's scheme untouched.
My pick
Peppercorn violet, with no accent as the serious alternative if you want the tool to disappear into the user's terminal entirely. Violet is the only choice that stays distinct from every status colour all the way down to 16 colours, and it keeps faith with the magenta already in the code.
If violet feels too loud
Use it at one cell, not one row: keep the bp anchor and the : prompt coloured, but make the selected row and the mode badge reverse video. That is a two-line change and lands halfway between the violet and the no-accent option.
What does not change
The logo in 1a is built from block glyphs and carries no colour information, so it works under any of these — including no accent at all. Whatever you pick paints the mark; it is not designed around the hue.

The row budget

Portrait Termux at default font: about 44 columns × 30 rows. Open the keyboard and the terminal shrinks to 12 rows.
So every screen is authored to 12 rows and 44 columns. Status pins to the top row, actions pin to the bottom row, content scrolls between. Nothing important is ever in the middle of a long list.
Anything that needs more than 12 rows is a separate screen, not a scroll.
No chords. Ever.
A soft keyboard has no Ctrl and no Esc. Digits and : sit on the symbol layer — two taps and a context switch. Only lowercase letters are one tap, so every key on the critical path is one.

Rows are labelled left-hand (a s d f g h), actions are named right-hand mnemonics. Pick with one thumb, act with the other. Overflow rows take z x c v.

Attach is stock zellij, exactly as on desktop — blackpepper renders nothing here and owns no zellij config. Zellij's own status bar already degrades: at 44 columns the mode labels drop and only the keys remain. Tab names truncate rather than wrap.

feature/auth! asks
No shade tiers exist here, so separation falls back to what every terminal has: a blank column, a dim uppercase label, and reverse video for selection and the mode badge. Accent becomes reverse or yellow. Nothing in the layout moves — only the paint changes.
Why borderless
Rounded boxes cost two rows and two columns per panel and draw more attention than anything inside them. Shade tiers cost nothing, and on a 16-color terminal the panels simply merge into a labelled column layout that still reads.
Where the accent is allowed
Exactly four places: the bp anchor, the mode badge, the selected row, and the : prompt. Everything else is a named ANSI color the user's theme already owns.
Ratatui reality check
Shade tiers keep the existing blend_color approach — 6% for a raised surface, no border style needed. Selection moves from a 16% blend to Modifier::REVERSED so it is correct on every color tier.
Glyph budget
● ○ ◐ ▸ ! ✓ × ? ⚠ ⠹ and half-blocks. All are in the BMP and present in every common terminal font; each has an ASCII fallback (* o . > ! + x ? ! -) behind one config flag.
