workflow

Leave the terminal. Keep the work.

  1. 01Open a folderRun bp. The current folder becomes a workspace.
  2. 02AttachEnter opens its Zellij session on the machine that owns the folder.
  3. 03WorkRun shells, configured services, Codex, Claude Code, or OpenCode in tabs.
  4. 04ReturnDetach and reattach later. Blackpepper never claims to resume agent conversations.

capabilities

One clear layer over tools you already trust.

01

Local + SSH

The same workspace view for local folders and folders on Linux OpenSSH hosts.

02

Persistent sessions

Zellij keeps the session alive where it runs; quitting Blackpepper leaves it running.

03

Coding agents

Spawn Codex, Claude Code, and OpenCode in explicit, workspace-scoped tabs.

04

Safe worktrees

Worktrunk mutations show the exact command and project hooks before :approve.

Loopback forwarding

commands

Everything explicit.

Commands run inside the TUI. Use Left and Right Arrow to browse these website command groups.

:workspace add <path>register a folder

:workspace switch <name|id>attach to a workspace

:worktree create <branch> [--base <ref>]preview creation

:worktree removepreview removal

:agent spawn <codex|claude|opencode>start an agent tab

:service start <name>start a configured service

:status explainshow redacted evidence

:refreshrefresh live state

:host add <name> <ssh-alias>register an OpenSSH alias

:host connect <name>connect interactively

:ports [--all-host]discover listeners

:forward <port|address:port>forward one exact listener

:approverun the exact reviewed plan

:helpshow the command reference

:quitdetach and exit

:workspace terminateend the session, keep the folder
